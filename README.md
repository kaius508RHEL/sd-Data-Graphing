# sd-Data-Graphing
Graphing program for visualizing collected sensor data in JSON format.

# System requirements for build
- Java 17 or higher
- Maven 4 (for manual program build)
- Windows, macOS, Linux
## How-to build:
- Download repo (zip or clone) (https://github.com/UBC-SUBC/sd-Data-Graphing.git)
- extract and ``cd`` to folder
- run ``./build.sh`` (macOS/Linux) or ``build.bat`` (Windows)

  NOTE: Execute  ``chmod +x ./build.sh`` if ``build.sh`` does not run.

# System requirements for installer
- Java 17 or higher
- Windows (10/11) (for installer)

## How-to install:
- download installer from Release page (https://github.com/UBC-SUBC/sd-Data-Graphing/releases)
- double click installer
- follow one screen instructions
